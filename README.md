# Front-End Practice Collection

A curated set of four front-end practice projects covering semantic HTML, responsive layouts, CSS styling, forms, landing pages, and dashboard UI.

## Projects

| Project | What it demonstrates | Entry point |
| --- | --- | --- |
| **01 — HTML Profile & CV** | Semantic HTML, sections, lists, tables, accessible forms | [Open page](01-HTML-CV-Profile/index.html) |
| **02 — Developer Hero Card** | Responsive hero layout, Flexbox, typography, call-to-action links | [Open page](02-Developer-Hero-Card/index.html) |
| **03 — CodeWave Bootcamp UI** | Landing page, login-card UI, form semantics, responsive styling | [Open page](03-CodeWave-Landing-Login/index.html) |
| **04 — Landing Page & Dashboard** | Image overlays, navigation, dashboard cards, sidebar, tables | [Landing page](04-Landing-Page-and-Dashboard/landing-page.html) · [Dashboard](04-Landing-Page-and-Dashboard/dashboard.html) |

## Tech Stack
- HTML5
- CSS3 (Flexbox, Grid, responsive media queries, transitions)
- Vanilla JavaScript for small client-side demo interactions

## Run Locally
1. Clone or download this repository.
2. Open any project's HTML entry point in a modern browser.
3. No build tools or package installation are required.

## Important Notes
- These are front-end learning exercises and static UI demonstrations.
- The contact and login forms do **not** connect to a backend, send messages, or authenticate users.
- Dashboard figures and table rows are sample data, not live business metrics.
- The avatar-themed landing page uses the included assets/download.webp background image.

## Learning Focus
The collection preserves the original exercises while improving structure, accessibility, responsiveness, asset paths, and clarity about what is and is not functional.
